Struktur Konten Utama

Setelah hero — konten dipecah bagaimana?

A

Single Column

Konten satu alur ke bawah — berita, lalu layanan, lalu statistik. Simpel dan fokus untuk mobile-first.

B

Duo Blue–White (Kiri Biru, Kanan Putih)

Kolom kiri warna biru: transparansi + program inovasi. Kolom kanan putih: berita + layanan. Mirip portal Jawa Timur — terstruktur dan resmi.

C

Grid Cards

Konten dalam kartu-kartu grid tanpa pemisahan warna blok. Lebih modern dan ringan — cocok gaya Si-Manggis.
